01

Get started in 3 steps

1
Get a free API key

Sign up at Deepgram (recommended — $200 free credit) or AssemblyAI ($50 free credit). No credit card required for either.

2
Paste your key into the app

In the app, select your service (Deepgram or AssemblyAI), then paste your API key into the API Key field. The key stays in your browser — it is never sent anywhere except directly to the service you chose.

3
Start recording or upload a file

Choose Live Mic for real-time auction transcription, or File Upload to process a recording. When finished, click Download Excel to get your formatted spreadsheet.

04

Live mic recording

Use this mode during an active auction to get a real-time running transcript on screen as the auctioneer speaks.

1
Select Deepgram and paste your key

Live mode only works with Deepgram. Make sure the Deepgram tab is selected and your key is entered.

2
Fill in auction details (optional but recommended)

Adding the auction name, date, location, and auctioneer means this info is automatically included in your Excel export.

3
Click "Start Recording"

Your browser will ask for microphone permission — click Allow. The status indicator turns red and the transcript begins appearing within a second or two.

4
Click "Stop" when finished

Then click Download Excel to save your transcript immediately.

Tip: For best accuracy, position your microphone or laptop close to the auctioneer. Auctioneers speak fast — the closer the mic, the more words the AI catches correctly.
05

Transcribing recorded files

Use this mode to transcribe an audio or video recording of a past auction. Works with both Deepgram and AssemblyAI.

1
Switch to "Upload File" mode

Click the File Upload button in the Mode section of the left panel.

2
Drop or browse for your audio file

Supported formats: MP3, WAV, M4A, OGG, FLAC, MP4, WEBM. Files can be any length.

3
Click "Transcribe File"

The file uploads directly to your chosen service. Deepgram returns results in seconds. AssemblyAI may take 1–3 minutes depending on file length — a status timer shows progress.

4
Download Excel when complete

The transcript appears on screen and the Download Excel button becomes active.

Understanding the Excel export

Each download is a .xlsx file named after your auction (e.g. Estate_Sale_42_transcript_2026-04-26.xlsx) with three sheets:

📋Sheet 1 — Transcript: Full formatted transcript with your auction name, date, location, and auctioneer in the header. Includes timestamps, speaker labels, and word count per line.
📊Sheet 2 — Speaker Summary: Each identified speaker listed with total lines spoken, total word count, and percentage of the conversation.
🗃️Sheet 3 — Raw Data: Clean, flat table with all fields — ideal for importing into other systems, filtering in Excel, or running your own analysis.
07

Tips for auction audio

🎙️Position the mic as close to the auctioneer as possible. Auction rooms are noisy — distance and background chatter are the biggest causes of transcription errors.
📋Fill in the auction name, date, location, and auctioneer fields before you start. This information gets embedded in the Excel header automatically — much easier than adding it later.
🏷️Deepgram lets you add custom vocabulary (lot names, item types, company names) in the Deepgram console under Settings → Custom Models. This significantly boosts accuracy for specialized auction terms.
🔊If you're recording a multi-auctioneer session, speaker diarization will assign a number to each distinct voice. You can rename them in Excel afterward (e.g. change "Speaker 1" to "John").
📁For recorded files, MP3 and WAV tend to produce the best results. If you're recording on a phone, use the built-in Voice Memos app (iPhone) or Recorder app (Android) and export as M4A or WAV.
💾Download your Excel file before closing the browser tab. The transcript is held in memory only — refreshing or closing the page clears it.
08

Troubleshooting

?
"WebSocket error — check your API key"

Your Deepgram key is either invalid or was pasted incorrectly. Go back to console.deepgram.com, copy your key again, and re-paste it. Make sure there are no extra spaces.

?
Microphone access denied

Click the lock icon in your browser's address bar and allow microphone access for this site. Then refresh the page and try again.

?
File upload fails with AssemblyAI

AssemblyAI requires the file to upload to their servers first, which can take a minute for large files. If it times out, try a shorter clip to verify your key is working, then try the full file again.

?
Transcript is empty after recording

Make sure your microphone is picking up sound — check your system audio settings and confirm the correct input device is selected. Try speaking directly into the mic to test.

?
The app works offline?

No — an internet connection is required to send audio to Deepgram or AssemblyAI for transcription. The app itself needs no install, but it calls the AI service APIs in real time.

Putting it on GitHub

Hosting on GitHub Pages gives you a permanent public URL for the app — no server, no cost.

1
Create a new repo on GitHub

Go to github.com/new, name it auction-transcriber, set it to Public, and click Create.

2
Push your files

Open a terminal in your project folder and run:

git init git add . git commit -m "Initial commit — AuctionScribe" git branch -M main git remote add origin https://github.com/YOUR_USERNAME/auction-transcriber.git git push -u origin main
3
Enable GitHub Pages

In your repo on GitHub, go to Settings → Pages. Under Source, select Deploy from a branch, choose main, and click Save.

4
Your app is live

Within a minute, your app will be available at:
https://YOUR_USERNAME.github.io/auction-transcriber
The help page will be at the same URL with /help.html added.
